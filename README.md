# Bounce ZX Spectrum
This is a re-written version of Bounce and Bounce Redux for the ZX Spectrum; it started out life on the humble ZX81 as a simple bat and ball game, like a one player PONG clone.

The original game was released for the Sinclair ZX81 on 10th January 2012 when I was at the University of Derby studying Computer Games Programming and Computer Science. It wasn't very good, but I got something working.

The source was never under version control, but I did put it in PasteBin [here](https://pastebin.com/08xP2C9K)

On 9th January 2018, I rebuilt it from scratch using z88dk with a vastly superior structure, i.e., a frame counter and better ball direction controls. Although the source is lost, it may be downloaded [here](https://spectrumcomputing.co.uk/entry/33409/ZX81/Bounce_Redux)

This is my first real attempt to make a ZX Spectrum game that isn't in BASIC. It is mostly build in C using z88dk. I will use many of the ideas from Bounce Redux, but add colour, sound and even better ball handling.
